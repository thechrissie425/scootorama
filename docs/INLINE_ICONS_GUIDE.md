# Using Inline Icons in Blog Posts

This guide shows content creators how to add inline Scootorama icons to blog posts and other rich text content.

## What Are Inline Icons?

Inline icons are small, colorful icons that appear **within your text** to add visual interest and help readers quickly identify game features, powerups, metrics, and more.

### Example

Instead of writing:

> "Activate the aero powerup for maximum speed on flat sections!"

You can write:

> "Activate the ⚡ (aero powerup icon) for maximum speed on flat sections!"

## How to Add Icons in Sanity Studio

### Step 1: Position Your Cursor

Click where you want the icon to appear in your text.

### Step 2: Insert Icon

1. Look for the **⚡ icon button** in the rich text toolbar
2. Click it to open the icon picker
3. Select your desired icon from the dropdown
4. Choose the size (Small, Medium, or Large)
5. Click "Insert"

### Step 3: Continue Writing

The icon will appear inline with your text. You can continue typing normally around it.

## Icon Sizing Guide

Choose the right size based on context:

### Small (16px)

- Best for: Dense text, footnotes, inline references
- Example: "The ⚡ powerup lasts 30 seconds"

### Medium (20px) — **DEFAULT**

- Best for: Body text, standard paragraphs
- Example: "Activate ⚡ for climbing segments"

### Large (24px)

- Best for: Headings, callouts, emphasis
- Example: "## Using ⚡ Effectively"

## Best Practices

### ✅ DO:

1. **Use icons sparingly** - 1-3 icons per paragraph maximum
2. **Choose relevant icons** - Match icon to content context
3. **Write descriptive alt text** - The icon name is automatically set, but ensure context is clear
4. **Test readability** - Make sure icons enhance, not distract
5. **Use consistent sizing** - Stick to one size per paragraph

### ❌ DON'T:

1. **Don't overuse icons** - Too many = visual clutter
2. **Don't replace all words** - Icons supplement text, not replace it
3. **Don't mix icon sizes randomly** - Keep sizing intentional
4. **Don't use icons in headings** (unless large size)
5. **Don't forget about accessibility** - Screen readers will announce icon names

## Accessibility Notes

All inline icons are automatically accessible:

- **Screen readers** will announce the icon name (e.g., "aero powerup")
- **Keyboard navigation** works normally around icons
- **High contrast mode** compatible

However, always ensure your text makes sense **without** the icons. Example:

✅ **Good**: "The aero powerup ⚡ reduces drag by 20%"  
❌ **Bad**: "The ⚡ reduces drag by 20%" (unclear what ⚡ refers to)

## Troubleshooting

**Icon not appearing?**

- Refresh the preview
- Check that you selected a valid icon from the dropdown
- Verify your Studio is up to date

**Icon too large/small?**

- Edit the icon by clicking it
- Change the size setting
- Save and refresh preview

**Want to remove an icon?**

- Click the icon in the editor
- Press Delete or Backspace
